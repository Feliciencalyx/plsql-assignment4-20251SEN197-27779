## 3. Project Description

The Student Registration and Grading Management System is a database application developed using Oracle SQL and PL/SQL.

The system manages student information, available courses, course registrations, and student grades.

It demonstrates how PL/SQL programming concepts can be used to manage university academic records efficiently.

## 4. Project Objectives

- Manage student information.
- Store available university courses.
- Register students for courses.
- Record and retrieve student grades.
- Calculate student academic results.
- Demonstrate advanced PL/SQL programming concepts.

## 5. Technologies Used

- Oracle Database 26ai

- PL/SQL
- Visual Studio Code
- Git and GitHub

## 6. PL/SQL Concepts Demonstrated

1. User-defined records and `%ROWTYPE`.
2. Associative arrays and other PL/SQL collections.
3. Implicit cursors.
4. Explicit cursors.
5. BULK COLLECT and FORALL.
6. Stored procedures.
7. Stored functions.
8. Exception handling.

## 7. Project Structure

- `00_schema/` – Database tables and sample data.
- `01_procedures/` – Stored procedures.
- `02_functions/` – Stored functions.
- `03_tests/` – Successful and error test cases.
- `screenshots/` – Evidence of execution.
- `docs/` – Implementation and performance notes.

## 8. How to Run

1. Connect to the appropriate Oracle database PDB.
2. Execute `00_schema/01_create_tables.sql`.
3. Execute `00_schema/02_insert_sample_data.sql`.
4. Compile all stored procedures.
5. Compile all stored functions.
6. Execute the success and error test scripts.
7. Review the execution results and screenshots.
